Humateck New198 setup

Applied flow:
Plan Page -> Email Verification -> browser email autocomplete -> Verify Email -> Order Page or Checkout.

Files:
- plans.html
- signup.html
- order.html
- supabase-config.js
- supabase-membership.js
- supabase_schema.sql

Important:
- OAuth is not a membership condition.
- Email verification loads membership status.
- Free trial and paid members stay separated in Supabase tables.
- Free trial is a 7-day subscriber plan with 15-country limit.
- Free trial end time is handled down to seconds.

Before deployment:
1. Run supabase_schema.sql in Supabase SQL Editor.
2. Put Supabase URL and anon key into supabase-config.js.
3. Upload these files to the English/global site.
