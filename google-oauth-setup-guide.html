Google OAuth Setup Guide
From Project Creation to Client ID Issuance

A step-by-step walkthrough of the Google Cloud Console setup required to connect the YouTube Data API v3.

01Creating a Google Project 02Creating a Google Client ID
1

Creating a Google Project

A Google Project is required before you can obtain Google OAuth verification (a Client ID). Follow the steps below.

1
Do you already have a Google Project? — No.
2
You'll need to create a Google Project first in order to obtain Google OAuth verification (Client ID).
Open the link below and create a new project.
Create a Google Project → https://console.cloud.google.com/projectcreate
3
Your Google Project has been created.
TIP. Your project name and project ID can always be found later at the top of the Console dashboard.
2

Creating a Google Client ID

Once your Google Project is ready, the next step is to issue an OAuth Client ID.

1
Do you already have a Google Project? — Yes.
2
Go to the Create a Google Client page. You'll see "Application Types."
Create a Google Client → https://console.cloud.google.com/auth/clients/create
3
Open the "Application Types" dropdown and select "Web applications."
4
Enter any name you like in the "Name" field.
5
Scroll down and you'll see "Approved JavaScript origins" and "Approved redirect URI." Enter "https://humateck.com" in each, then click the "CREATE" button at the bottom.
6
Your Client ID and Client Secret are generated. Be sure to copy and store both values somewhere safe, then click "OK" in the bottom-right corner.
⚠ Once you close this dialog, the Client Secret cannot be viewed again. Make sure you've saved it before continuing.
7
Your Client ID now appears in the list. This ID is your Google OAuth authentication key.
TIP. The Client ID and Client Secret are used as-is when configuring OAuth login for the YouTube Data API v3. Keep them private and never expose them publicly.
