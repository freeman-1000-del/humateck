구글 OAuth 설정 가이드
프로젝트 생성부터 클라이언트 ID 발급까지

YouTube Data API v3 연동을 위해 꼭 필요한 구글 클라우드 콘솔 설정 절차를 따라하기 쉽게 정리했습니다.

01구글 프로젝트 만들기 02구글 클라이언트 ID 만들기
1

구글 프로젝트 만들기

구글 OAuth 인증(클라이언트 ID)을 받으려면 먼저 구글 프로젝트가 있어야 합니다. 아래 순서대로 진행해 주세요.

1
구글 프로젝트가 있으신가요? — 없습니다.
2
먼저 구글 프로젝트부터 만드셔야 구글 OA 인증(클라이언트 ID)을 받을 수 있습니다.
아래 링크로 이동해 새 프로젝트를 생성해 주세요.
구글프로젝트 만들기 → https://console.cloud.google.com/projectcreate
3
구글 프로젝트가 만들어졌습니다.
TIP. 프로젝트 이름과 프로젝트 ID는 나중에 콘솔 대시보드 상단에서 언제든 확인할 수 있습니다.
2

구글 클라이언트 ID 만들기

구글 프로젝트가 준비되었다면, 이제 OAuth 클라이언트 ID를 발급받을 차례입니다.

1
구글 프로젝트가 있으신가요? — 네.
2
구글 클라이언트 만들기 페이지로 이동하세요.
구글 클라이언트 만들기 → https://console.cloud.google.com/auth/clients/create?project=fourth-cedar-489307-b1
3
'Application Types'에서 드롭다운 메뉴를 눌러 'Desktop App'을 선택합니다.
4
'Name' 칸에 임의의 이름을 입력하고 하단의 'CREATE' 버튼을 누릅니다.
5
클라이언트 ID와 클라이언트 보안 비밀번호가 생성됩니다. 두 값을 반드시 복사하여 안전한 곳에 저장한 뒤, 우측 하단의 'OK'를 누르세요.
⚠ 이 창을 닫으면 클라이언트 보안 비밀번호는 다시 확인할 수 없습니다. 저장 여부를 꼭 확인해 주세요.
6
클라이언트 ID가 목록에 등록된 모습입니다. 이제 발급받은 구글 클라이언트 ID를 사용하시면 됩니다.
TIP. Client ID와 Client Secret은 YouTube Data API v3 OAuth 로그인 설정 시 그대로 사용됩니다. 외부에 노출되지 않도록 주의해 주세요.
