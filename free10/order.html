A) This is because YouTube content display system fixes the default video setting to U.S. English when multilingual translations are registered. However, this is not an error, and you may edit your native-language title or description at any time. Please do not misunderstand this point.

Important Setup Guide

Google OAuth authorization guide for first-time users.

This setup may feel unfamiliar at first. It is the official Google authorization process required to register multilingual content to your YouTube video.

A Google OAuth Client ID is generally reusable for a considerable period after setup, but reconfiguration or reauthorization may be required due to token expiration from heavy usage or other reasons.

Step 1. Go to Google Cloud

Click the button below to open the Google Cloud setup page.

Open Google Cloud

Sign in with the Google account you will use for YouTube registration.

Step 2. Enable YouTube Data API v3

Search for YouTube Data API v3 in Google Cloud and enable it.

This API must be enabled to send multilingual title and description registration requests to YouTube.

Step 3. Enter Branding information

Open Branding from the left menu.

  • Enter an easy-to-recognize name in App name.
  • Select your Google email for User support email.
  • Enter a reachable email under Developer contact information.

Step 4. Check Target / Test users

Open Target from the left menu.

If the app is in testing status, add the Google email that will perform authorization under Test users.

Step 5. Create a Web application OAuth Client

Open Client, then select Create client.

The application type must be Web application.

Step 6. Add Authorized JavaScript origins

To authorize directly from the website, add the website origin you are using.

  • Official site example: https://humateck.com
  • If using www: https://www.humateck.com
  • For local testing: http://localhost:5500 or your actual localhost origin

Do not add a trailing slash or a path such as /order.html.

Step 7. Copy the OAuth Client ID

Copy the generated Client ID and paste it into the Google OAuth Web Client ID field on the order page.

The input may be masked for security.

Step 8. Click Google Authorization

Click Google Authorization on the order page to open the official Google authorization window.

The Google account must have edit permission for the target YouTube channel or video.

Important Notice

If the same Google account has management permission for multiple channels, you can proceed by entering the actual YouTube video URL for each target video.

A Google OAuth Client ID is generally reusable for a considerable period, but reconfiguration or reauthorization may be required due to token expiration from heavy usage or other reasons.

This is a normal Google security process for account protection and YouTube API usage, not a service error.
